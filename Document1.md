# What GitHub Is

- **Developer platform:** Supports the entire software development lifecycle (planning, coding, reviewing, testing, deploying, and monitoring).
- **Git integration:** Built on Git, an open-source version control system that tracks changes and enables safe collaboration.
- **Collaboration hub:** Teams can work together on projects, review code, and manage issues in real time.

# Core Features

- **Repositories:** Store and manage code with version control.
- **Issues & Projects:** Track bugs, tasks, and milestones.
- **Pull Requests:** Propose, review, and merge code changes.
- **Actions:** Automate workflows like CI/CD, testing, and deployments.
- **Security tools:** Built-in vulnerability scanning, secret protection, and supply chain security.
- **Community:** Discover, fork, and contribute to open-source projects.
